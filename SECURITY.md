# Security Policy

This repository is an educational competitive programming reference, not a production package. Most contributions are algorithm solutions and notes.

## Reporting a vulnerability

If you find a security issue related to repository automation, GitHub Pages behavior, or scripts in this repo, please report it privately through GitHub's security advisory flow if available. If advisories are not enabled, contact the maintainer through the repository's GitHub contact path.

Please include:

- A clear description of the issue.
- Steps to reproduce it.
- The affected file, workflow, or page.
- Any suggested fix, if known.

Avoid opening public issues for vulnerabilities until the maintainer has reviewed the report.

## Supported versions

Only the default branch is maintained.
