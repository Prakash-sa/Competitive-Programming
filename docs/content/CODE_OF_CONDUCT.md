# Code of Conduct

## Our standards

This project welcomes contributors who communicate respectfully and focus on improving the repository. Expected behavior includes:

- Using clear, constructive language in issues, pull requests, and reviews.
- Giving technical feedback without personal attacks.
- Respecting different experience levels and backgrounds.
- Keeping discussions relevant to the repository.
- Accepting maintainer decisions when a contribution does not fit the project scope.

Unacceptable behavior includes harassment, insults, discriminatory language, threats, doxxing, spam, or repeated off-topic disruption.

## Enforcement

Maintainers may edit, hide, or delete comments; close issues or pull requests; or block contributors who violate this code of conduct. Enforcement decisions are based on the impact of the behavior, not only intent.

## Reporting

If you see a conduct issue, contact the maintainer through the repository's GitHub contact path. Include links, screenshots, or context when possible. Reports will be handled with care and shared only with people needed to review and act on the issue.
